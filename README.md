# Daniel-devops-practica

## Proyecto DevOps Práctica 2.1

**Nombre:** Daniel Lado Figueroa

**Descripción:** Esta es una aplicación Python para practicar control de versiones con Git y GitHub.

## 🐳 Ejecución con Docker

### Prerrequisitos
- Tener Docker instalado.

### Construcción de la imagen
Para construir la imagen localmente, ejecuta:
```bash
docker build -t mi-tienda-app .
```

### Ejecutar el contenedor
Para lanzar la aplicación:
```bash
docker run --rm mi-tienda-app
```

### Prueba rápida
Al ejecutar el contenedor deberías ver en la consola la salida del `main.py` (usuarios, inventario y pedidos).
